# SilveradoAdapters
2019-2026 Silverado T1XX Speaker Adapters

Aftermarket Speaker Adapter STL files for 3D Printing. Specifically modeled for Morel Maximo Ultra 602 mkii 3-Way component and Coaxial speakers.
-Front door adapters hold the 6.5" woofer and tweeter.
-Dash adapter holds the 3" midrange.
-Rear door adapter hold the 6.5" coaxial.
-Adapter shield to protect the speaker from drainage water.

Front door adapter has a split option that can be glued together if your printer area is limited.
